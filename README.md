# The Palms — меню с Google Таблицей и авто-переводом

Правите меню в **Google Таблице** (RU + EN), GitHub Actions сам переводит
на арабский, немецкий, французский, итальянский и испанский и обновляет сайт
на GitHub Pages.

## Как это работает

```
Google Таблица (RU/EN + пустые auto-колонки)
      │  раз в 6 часов / по кнопке / при пуше
      ▼
GitHub Action: tools/build_menu_data.py
  1. читает таблицу (достаточно доступа «по ссылке»)
  2. берёт RU/EN как есть; auto-колонки: ручной текст имеет приоритет,
     пустые — переводит (DeepL, если задан ключ, иначе MyMemory)
  3. кэширует переводы в translate-cache.json (лимиты не тратятся повторно)
  4. пишет menu-data.js и коммитит
      ▼
GitHub Pages отдаёт index.html + menu-data.js
(если menu-data.js нет/не загрузился — страница работает на встроенных данных)
```

## Установка (один раз)

1. Создайте репозиторий и залейте туда содержимое этого архива:
   `index.html`, `menu-data.js`, `base-i18n.json`, `translate-cache.json`,
   папки `tools/` и `.github/`.
2. В Google Sheets: **Файл → Настройки доступа → «Все, у кого есть ссылка»**
   (роль «Просмотр»). Скопируйте ID таблицы из URL:
   `https://docs.google.com/spreadsheets/d/<ВОТ_ЭТО_ID>/edit`
3. В репозитории: **Settings → Secrets and variables → Actions**:
   - вкладка *Variables* → New repository variable: `SHEET_ID` = ID таблицы
     (если лист не первый, добавьте переменную `SHEET_GID` из `#gid=` в URL);
   - вкладка *Secrets* → New repository secret: `DEEPL_API_KEY` —
     бесплатный ключ на api-free.deepl.com (500 000 символов/мес).
     Без ключа перевод идёт через MyMemory (~5000 символов/день — медленно).
4. **Actions → Update menu translations → Run workflow** — проверьте, что
   всё собралось.
5. **Settings → Pages → Source: Deploy from a branch → main / (root)**.

## Работа с меню

- Правите только колонки **Название (RU), Описание (RU), Name (EN),
  Description (EN)** и, при желании, **Аллерген** (S/V/N).
- Колонки Arabic/German/French/Italian/Spanish («auto») **оставляйте
  пустыми** — перевод появится сам после прогона Action. Если впишете текст
  туда сами — он победит автоперевод.
- Добавили блюдо в таблицу — оно появится на сайте после прогона Action.
  Категорий может быть максимум 4 (ограничение дизайна страницы), новые
  категории подхватываются по порядку. Опции «мезе» и «фахита» сохраняются
  за блюдами с именами *Mezza selection, cold & hot* и *Your choice of fajita*.
- Расписание: каждые 6 часов + вручную. Кэш переводов в `translate-cache.json`
  не даёт переводить одно и то же дважды.

## Важно

- Не редактируйте `menu-data.js` руками — он перезаписывается.
- Названия категорий на других языках берутся из шаблона `base-i18n.json`
  (RU-название подтягивается из таблицы).
